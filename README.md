🚀 CodePath – Programming Path Finder

CodePath is an interactive website designed to help users discover the programming field that best matches their interests and preferences.

✨ Features

- Interactive programming path quiz
- Personalized results based on user answers
- Multiple programming paths:
  - Front-End Development
  - Back-End Development
  - Game Development
  - Mobile Development
  - AI & Data Science
- Dark and Light themes
- Simple and user-friendly interface

🌐 Live Demo

"Visit CodePath" (https://mahdis-shariat.github.io/Codepath-Website/)

🛠️ Technologies

- HTML
- CSS
- JavaScript

🎯 Purpose

The goal of this project is to make exploring programming fields easier and more engaging for beginners.
